# RuClaude Browser v1.0.1

Browser privacy guard for Claude on Chromium and Firefox.

- Country-based public IP check and optional time-zone validation.
- Optional WebRTC checking; language settings.
- Updated extension UI and usage tips.

**Firefox support is experimental.** Browser checks do not guarantee network-level blocking when VPN routing changes.

Install: extract the browser ZIP and load the unpacked extension. Firefox may require temporary installation or Mozilla signing.
