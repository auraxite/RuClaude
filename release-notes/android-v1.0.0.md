# RuClaude Android v1.0.0

Android protective launcher for Claude. Checks the public IP country before opening the official Claude app.

- Russian/English interface.
- Saved allowed-country selection.
- Fresh public-IP check before launch, independent of VPN provider.

**Source distribution only:** build the APK in Android Studio (Gradle 9.6.0, Android Gradle Plugin 9.4.0, SDK 37). This launcher cannot block Claude traffic launched directly or after a VPN route change.
